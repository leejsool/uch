# UniverCityHunter — 폴더 구조

```
univercityhunter.html      코드. 이것만 고칩니다
build-single.py            배포용 한 파일 만들기
art/
  title.webp               시작 화면 (지금 들어 있음)
  npc/                     담당자 얼굴 (비어 있음)
  item/                    아이템 아이콘 (비어 있음)
  fac/                     본진 시설 그림 (비어 있음)
  intro/                   오프닝 배경 (비어 있음)
```

## 그림 붙이는 법

파일을 폴더에 넣고, 코드 위쪽 표에 **파일 이름만** 적습니다.
빈 칸("")이면 지금처럼 이모지나 글자로 나오니, 하나씩 채워도 됩니다.

```js
const ITEM_ART={ ladle:"item/ladle.webp", pen:"item/pen.webp" };
const NPC_ART ={ office:"npc/office.webp", shop:"", ... };
const FAC_ART ={ clinic:"fac/clinic.webp", gate:"fac/gate.webp", ... };
const INTRO_ART={ gate:"intro/gate.webp", crowd:"", ... };
```

권장 크기 — 아이템 64×64 / 얼굴 256×256 / 시설 128×128 / 오프닝 1080×720.
형식은 WebP를 권합니다. PNG보다 3~5배 작습니다.

## 배포용 한 파일 만들기

```
python3 build-single.py
```

`univercityhunter-single.html` 이 나옵니다. 그림까지 전부 들어간 한 파일이라
메신저로 그냥 보내도 됩니다. art 폴더는 필요 없습니다.

## 배포 전 확인

- 코드 맨 위 `DEV_SHOW_UNLOCK` 을 `false` 로
